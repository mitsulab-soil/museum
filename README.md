# 森羅美術館・森羅図書館（Shinra Museum & Library）

mitsulab の連作《森羅百景》の作品を、3D の館で見る・読むためのページです。

- **森羅美術館を巡る**：入口から歩いて円堂へ。八つの部屋（つち・あめ・かぜ・ゆき・いきもの・やさい・つき・たいよう）に入るたび、光と音が変わります。気になる作品の前で立ち止まると、案内役の碧（あおい）が声で話します（字幕つき）。
- **森羅図書館で読む**：円堂のまん中の光の輪から、地下の閲覧室へ。書架の本を手にとると、見開きの本になって読めます。

ページ：<https://mitsulab-soil.github.io/museum/>
